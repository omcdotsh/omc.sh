# Design System Master — omc.

**Identity:** OMC Brand System (Swiss shell · spectrum expression · letterform frames)  
**Source:** Brand board + ui-ux-pro-max (Swiss Modernism 2.0, Portfolio Grid, Complex motion)  
**Dials:** Variance 7 · Motion 8 · Density 3

## Concept

Stable identity, fluid expression. Neutral chrome so every project can pick its own voice from the accent spectrum. The wordmark **omc.** and the **dot** are the only constants.

Visitors should feel **craft + clarity** — not a SaaS shell, not a hollow “agency” pitch.

## Positioning (product)

- Public label: **omc.** (nothing under the logo)
- Visual: creative-tech / Awwwards immersion
- Depth: lead eng + end-to-end product ownership
- Oscar: About / Experience + case bylines — **not** in the first viewport
- Proof first: Neutrl · Morpho
- Dual CTA equal weight: project (prospect) · experience (recruiter)

## Color

### Neutrals (shell)
| Token | Hex | Role |
|-------|-----|------|
| N50 | `#FAFAFA` | Light canvas |
| N100 | `#F4F4F5` | Subtle surface |
| N200 | `#E4E4E7` | Borders light |
| N400 | `#A1A1AA` | Muted text |
| N700 | `#3F3F46` | Secondary ink |
| N900 | `#18181B` | Near black |
| N950 | `#09090B` | Ink / dark canvas |

### Accent spectrum (expression — not a fixed brand color)
Red · Orange · Yellow · Green · Teal · Blue · Indigo · Purple · Pink  
Use on project frames, tags, hover floods, case chapters. Default interactive **dot** = Yellow `#F5C518`.

### UI chrome
- Light default: white/N50 bg, N950 ink, black primary CTAs
- Dark: N950 bg, N50 ink, white primary CTAs
- No permanent orange brand bar

## Type

- **Display / body:** Archivo (Suisse Intl stand-in until licensed files ship)
- **Mono:** IBM Plex Mono — meta, indexes, tags
- Display: tight tracking, bold/black weights, oversized heroes
- Body: regular, clear measure, no noise

## Grid

- 12 columns · gutter 24px · margin ~72px (desktop) / 24px (mobile)
- Container utility: `.omc-container`

## Components

- **Buttons:** pill (`rounded-full`) + arrow; primary solid ink; secondary outline; tertiary text
- **Tags:** pill + spectrum dot prefix
- **Frames:** letterform masks `o` / `m` / `c` / `.` for imagery
- **Dot:** cursor / focus / transition accent

## Motion

- Scroll reveals (short y, ~350–500ms)
- Dot follows pointer (respect `prefers-reduced-motion`)
- Spectrum flood on project rows
- Magnetic CTAs sparingly (1–2 focal)
- Page feel: immersive but CTA always legible

## Tone

Direct · Confident · Clear · Ambitious · Creative · Curious · Honest · Collaborative · Human  
“We speak like we build: with purpose, without noise.”

## Anti-patterns

- “Agency / studio led by…” slogans
- Fixed purple-on-white or terracotta cream clichés
- Laundry-list service heroes
- Soft generic cards in the hero
- Rainbow chrome competing with spectrum project accents
- Oscar name in viewport 1
